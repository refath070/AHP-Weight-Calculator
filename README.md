# AHP Hazard Weight Calculator

A standalone browser-based Analytic Hierarchy Process (AHP) calculator for hazard susceptibility, GIS, remote sensing, and MCDA.

## Main features
- 5–15 indicators / criteria
- 6–20 respondents / experts
- Full Saaty judgment scale from 1/9 to 9 with detailed interpretations
- Geometric-mean aggregation of group judgments
- Priority weights, percentage weights, and ranks
- λmax, CI, RI, CR, and explicit consistency status
- CR ≤ 0.10 shown as ACCEPTABLE
- Color-coded aggregated pairwise comparison matrix
- High-resolution PNG download for weight-percentage chart
- High-resolution PNG download for pairwise comparison matrix
- CSV export, browser save/load, print/PDF, and flash-flood demo

## Run locally
Open `index.html` in a modern browser. No server, Python, database, or installation is required.

## Publish
Upload `index.html`, `style.css`, and `script.js` to GitHub Pages, Netlify, or any static web host.

## Research note
Demo/random judgments are for learning and testing only. Replace them with real expert/respondent judgments before reporting research results.
