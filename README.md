# AHP Weight Calculator

A free, interactive, web-based **Analytic Hierarchy Process (AHP) Weight Calculator** developed for hazard assessment, susceptibility mapping, environmental studies, GIS and Remote Sensing applications, and Multi-Criteria Decision Analysis (MCDA).

The calculator allows researchers, students, and practitioners to perform AHP pairwise comparison and weight calculations directly in a web browser without requiring specialized software.

## Key Features

- Supports 5–15 criteria or indicators
- Supports 6–20 respondents or experts
- Full Saaty pairwise comparison scale from 1/9 to 9
- Group decision-making using geometric mean
- Automatic aggregated pairwise comparison matrix
- Automatic AHP criterion weights
- Weight percentage and ranking
- Maximum eigenvalue (λmax)
- Consistency Index (CI)
- Random Index (RI)
- Consistency Ratio (CR)
- Automatic consistency assessment
- CR ≤ 0.10 identified as acceptable
- Color-coded pairwise comparison matrix
- Publication-ready weight visualization
- Download comparison matrix as PNG
- Download weight-percentage figure as PNG
- Export results as CSV
- Save and reload calculations in the browser
- Built-in Flash Flood Susceptibility example
- Applicable to different hazards and MCDA problems

- Other AHP-based decision-making problems

## AHP Method

The calculator follows the Analytic Hierarchy Process developed by Thomas L. Saaty. Pairwise judgments are entered using the Saaty scale ranging from 1/9 to 9.

For group decision-making, judgments from multiple respondents are aggregated using the geometric mean. Criterion priorities are then derived from the aggregated reciprocal comparison matrix.

The calculator also evaluates judgment consistency using:

- Maximum eigenvalue (λmax)
- Consistency Index (CI)
- Random Index (RI)
- Consistency Ratio (CR)

A consistency ratio of **CR ≤ 0.10** is considered acceptable in the calculator.

## Important Research Note

The built-in random and Flash Flood examples are provided only for demonstration and learning purposes. For scientific research, thesis work, or publication, users should replace demonstration values with judgments obtained from appropriate experts or respondents and report the resulting consistency statistics.
